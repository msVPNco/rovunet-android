# تغییرات نسخهٔ آزمایشی 0.1.0-dev.3

- دسترسی Keychain در خود رابط متمرکز شد؛ کلید در حافظهٔ همان نشست نگهداری و
  هنگام خروج پاک می‌شود. Agent و نگهبان پراکسی دیگر Keychain را جدا باز نمی‌کنند.
  رد دسترسی باعث حلقهٔ درخواست رمز هنگام ذخیرهٔ عیب‌یابی نمی‌شود. فایل‌های قبلی
  با همان کلید و AES-GCM خوانده می‌شوند؛ ACL به همهٔ برنامه‌ها باز نشده است.
- منوی نوار وضعیت فرمان‌های فعال و عنوان‌های هم‌زبان برنامه دارد. اعتبار این
  مدل در تست رابط بررسی شد؛ نمایش بومی مک هنوز باید آزموده شود.
- فرم DNS برای هر خانواده جداست: DoH بدون فهرست IP ذخیره می‌شود، آدرس‌های
  تکراری/IPv6 و authoritative حفظ می‌شوند و اطلاعات ورود v33 از فرم تغییر می‌کند.
- اسکنر دو نمای تنظیمات و نتایج دارد: بانک/پروفایل/فایل/ورودی دستی/DNS شبکه،
  توقف و ادامه، چهار حالت، تست تونل و HTTPS واقعی در Agent جدا، فیلتر و ترتیب،
  چندانتخابی، خروجی متن و جزئیات، مخزن DNS و جایگزینی اختیاری ریزالور.
  پاسخ DNS به معنی عبور داده نیست. TCP صریح، کلید SSH و گواهی Slipstream حفظ می‌شوند.
- گزینهٔ VPN سراسری/TUN با نصب یک‌بارهٔ سرویس محدود اضافه شده است. UI و Agent
  با دسترسی عادی می‌مانند. سرویس فقط کنترل شروع/وضعیت/توقف و اتصال به SOCKS
  محلی دارای رمز را می‌پذیرد. UDP به توانایی پروتکل انتخابی وابسته است.
- DMG به نمای آیکونی Finder با اندازهٔ ۱۲۸ تنظیم شد؛ Applications یک پیوند واقعی است.

آزمون‌های Windows و شبکهٔ ایزولهٔ Linux در VERIFICATION.json ثبت‌اند. موفقیت
این آزمون‌ها به معنی تأیید نصب یا TUN روی مک نیست؛ همان بسته باید روی M3 آزمایش
شود. Kill Switch پایدار، تفکیک دستی برنامه‌ها و اسکن یک‌جای بانک‌های بسیار بزرگ
هنوز هم‌سطح ویندوز نیستند. بستهٔ قبلی و پوشه‌های ویندوز/اندروید تغییر نکرده‌اند.
