# Rovunet macOS 0.1.0-dev.6 — 预发布版

提供功能相同的原生 **Apple Silicon arm64** 和 **Intel x64** 安装包，均要求 **macOS 15 或更新版本**。请按处理器选择；Air/Pro 型号和屏幕尺寸无需单独的版本。

- 新增 AnyTLS、TUIC 和单绑定 Mieru（`mierus://`）的导入、编辑器及原生引擎。
- 每个集合的“连接选择方式”包含手动、故障时切换和智能选择。切换限制候选数量，确认测试结果并设置最短停留时间；新路径未通过确认时恢复旧路径。
- 粘贴、文件或二维码中的 HTTPS 订阅链接进入订阅预览。保留提供方报告的用量、剩余额度和到期时间；未知信息不会显示为无限。
- Slipstream 自动获取服务器证书，首次使用时请求确认指纹；已保存身份不会被静默替换。
- 更新状态图标颜色、已连接卡片的操作、本地应用代理（如 Telegram）以及伊朗狮子与太阳旗，保留 Mac 界面设计。

用 Command–Q 退出旧版本，再安装匹配的 PKG。保留配置和 Keychain 数据。同一架构下兼容的 TUN 服务无需重新安装。也提供拖到 Applications 的 DMG。

当前使用开发签名，尚无 Developer ID 签名或公证。这些安装包在真实 Mac 上的运行、Keychain、Installer 和 TUN 流量仍待确认。完整或多绑定 Mieru 文档、任意链路、持久 Kill Switch 和强制按进程路由尚未完成。每批 DNS 扫描最多 2048 个地址。
