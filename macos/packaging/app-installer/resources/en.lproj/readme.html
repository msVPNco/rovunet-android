Rovunet 0.1.7 Beta 1 for macOS

Requires macOS 15 or later. Use the Apple Silicon package for M-series Macs and the Intel x64 package for Intel Macs.

The menu beside the clock updates with the app language. In the DNS editor, select Find DNS, run a scan, tick a usable result and choose Apply at the top. It updates the same configuration.

An installed dev.3 TUN service of the same architecture remains compatible. For a first installation, use Settings → Install / update TUN service, then enable System-wide VPN (TUN).

Beta release: the Apple Silicon functional base was tested and accepted by the owner. Intel has limited testing. This update retains existing profiles and the compatible TUN service.
