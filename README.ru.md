# Rovunet

**Многопротокольный VPN-клиент Android для нескольких путей к собственному серверу.** Объединяет DNS-туннели, транспорты SSH, HTTPS-прокси и профили Xray. Связанные пути хранятся в коллекциях: подключайте выбранный напрямую или отдельно измеряйте HTTPS через настоящий туннель.

[Выпуски](https://github.com/msVPNco/rovunet-android/releases) · [Telegram](https://t.me/RovunetVPN) · [Панель](https://github.com/msVPNco/rovunet-panel) · [Руководство](docs/USER_GUIDE.ru.md)

## Возможности

| Раздел | Поведение |
| --- | --- |
| Коллекции | Группировка по метаданным коллекции, аккаунта и сервера; сохранение явного выбора и завершённых измерений. |
| Подключение | Первое нажатие выбирает путь, повторное подключает выбранный. Раскрытие, редактор и меню не подключают. Пинг и сканирование пула не обязательны. |
| Проверки | HTTPS/204 через реальный туннель, проверка сертификата, ограниченная запасная цель, доля успеха и разброс задержки. DNS-этап проверки коллекции требует согласия. |
| Интерфейс | Светлая, тёмная и AMOLED-темы, различимые коллекции/пути, зелёные актуальные HTTPS-измерения сети, четыре языка, быстрые действия и счётчики. |
| Конфигурации | Предпросмотр ссылок/текста/файлов/QR, обмен, экспорт коллекции, резервные копии с паролем и явное восстановление секретов с сохранением ограничений. |
| Безопасность | Подтверждение SSH, проверка TLS и сохранённых самоподписанных идентичностей, шифрование сохранённых секретов, аутентификация приватного Xray SOCKS и отмена запуска. |
| Диагностика | Локальный отчёт этапов/кодов и снимки счётчиков; отправка только по действию пользователя. Нет автоматической загрузки и полей адресов, аккаунтов или секретов в безопасном отчёте. |

Основной интерфейс, настройки и ресурсы редактора доступны на персидском, английском, упрощённом китайском и русском. Некоторые унаследованные расширенные тексты сканера и ошибки движков могут оставаться английскими. Технические названия, адреса и синтаксис не переводятся.

## Протоколы

| Семейство | Пути |
| --- | --- |
| SSH | Прямой SSH, совместимые TLS/STunTLS-конфигурации, HTTP CONNECT, WebSocket; пароль или поддерживаемые ключи. |
| DNS | DNSTT, NoizDNS, VayDNS, Slipstream, Soar и поддерживаемые SSH-комбинации; поиск/настройка резолверов по возможностям движка. |
| HTTPS/прокси | NaiveProxy, NaiveProxy + SSH, удалённый SOCKS5, DoH. Обычный SOCKS5 не шифрует транспорт, отдельный DoH шифрует только DNS. |
| VLESS/ядро | VLESS WebSocket, REALITY, XHTTP, Hysteria2, стандартный WireGuard с одним peer через встроенное ядро. |
| Tor | Tor и поддерживаемые Snowflake/obfs4/Meek/пользовательские мосты в Full с учётом архитектуры и движка. |

**Новые Soar и Soar+SSH используют UDP + TCP по умолчанию.** Существующий/импортированный выбор сохраняется; Авто, UDP + TCP, только TCP и только UDP различаются. SSH поверх туннеля также требует разрешённых сервером адреса и порта.

Импортируются `rovunet://`, совместимые `veyra://`/`slipnet://`, поддерживаемые VLESS/Hysteria2 и WireGuard INI с одним peer. Родной экспорт — v33; неизвестные будущие версии явно отклоняются вместо неполного импорта. Произвольный JSON ядра, AmneziaWG и все разновидности WireGuard URI не заявлены.

## Использование и обновление

Проверьте предпросмотр импорта, откройте коллекцию, выберите путь и нажмите повторно либо используйте кнопку коллекции. Запомненный путь при возвращении уже выбран. Разрешите VPN; отпечаток неизвестного SSH/самоподписанной идентичности сначала сверьте с оператором. Фоновые задачи не подтверждают новые ключи автоматически.

Проверка отделена от подключения; прошлый неуспех не запрещает ручное соединение. «Подключено» означает техническую готовность, а не доступность каждого сервиса. Задержка HTTPS — не скорость загрузки или гарантия длительной стабильности.

Обновление скачивает совместимый GitHub APK внутри приложения и проверяет хеш, пакет, версию и подпись перед установщиком Android. Тихой установки и запасного зеркала нет; другую подпись нельзя автоматически превратить в совместимое обновление.

**Не удаляйте единственную читаемую копию профилей.** Публичная alpha11 и Rovunet Test имеют разные идентичности. Массовый экспорт с паролем исключает заблокированные профили; защищённым/привязанным к устройству могут понадобиться исходные ссылки или перевыпуск после смены подписи. [Миграция](docs/adr/0002-signing-transition.md).

## Панель и ограничения

[Панель](https://github.com/msVPNco/rovunet-panel) управляет поддерживаемыми службами Linux и экспортирует профили. Поддержка клиентом не означает автоматическую установку панелью; некоторым `core-plan` путям нужно ручное развёртывание. Требуются сервер и действительные учётные данные; бесплатных аккаунтов нет.

Не включены периодическое обновление подписок, автоматическая смена пути коллекции, тест пропускной способности и настольные/магазинные версии. Режим auto Soar и данные удалённого SOCKS в сообщённой сети требуют полевых свидетельств. Нет гарантии доступности в любой сети.

## Исходники, проверки и поддержка

ZIP включают код, ресурсы, тесты, лицензии и доступные закреплённые исходники native-компонентов. Лёгкий ZIP исключает готовые `.so`/`.aar`. `SOURCE-MANIFEST.json` фиксирует версии, повторно использованные бинарные файлы и недоступное старое дерево `dnstt-mobile`; полной независимой пересборки всех native-зависимостей не обещается.

[Сборка](docs/BUILDING.md) · [Публикация](docs/RELEASING.md) · [Безопасность](SECURITY.md) · [Форматы](VEYRA-CORE.md).

Для отчёта укажите версии приложения/Android, протокол, шаги и локальный безопасный отчёт. Не публикуйте конфигурационные ссылки, пароли, приватные ключи и ID устройств. Сообщество: [t.me/RovunetVPN](https://t.me/RovunetVPN).
