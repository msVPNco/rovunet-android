## Additional owner-reported update issue resolved

During implementation, the owner reported UNSUPPORTED_FORMAT updating the saved win collection. Read-only diagnosis reproduced it: two native Xray wrappers contained AmneziaWG options and an SS2022 method. The parser now reads the three supported SS2022 methods, validates PSK lengths and preserves identity-key chains; the editor lists those methods. Strict import, native version/schema validation and protected/TLS restrictions stay atomic. AmneziaWG remains unsupported and its options are never interpreted as regular WireGuard.

# Local UI review · 0.1.1-preview.1 · 2026-11-11

Private, owner-approved implementation of the six-view compact/expanded preview. Three shared palettes: light glass/lilac, dark blue glass and AMOLED. Default compact width is 480 logical pixels; sidebar width is 222. A full-window header centers the language flags independently of sidebar direction; narrow widths give flags a separate centered row. The English brand stays physically left inside its own frame, including Persian.

Profile cards have fixed 84-pixel height, separate latency and fixed 44-pixel actions. Overflow text moves inside clipped single-line fields at 24 pixels/second, with pauses; short text stays still. Motion defaults to on, reflecting the owner's explicit request. Settings offer on/off/follow Windows; high contrast stops motion. Unloaded/offscreen rows stop their animation clocks. This is native WPF animation, not a bitmap mockup or manual-only scrolling.

The hero shrinks from 148 to 88 while scrolling and retains the power button. Available monitor work area and DPI bound window geometry; short windows collapse the hero earlier. Actual physical touch, monitor migration and mixed-DPI hardware still need testing. A reported rendering tier is capability, not measured GPU utilization.

Connection/import/scanning/trust behavior is inherited from Beta. Only a display preference and fresh-window defaults changed in storage; existing saved window size is preserved if it fits. No new HY2/WireGuard engine or TUN implementation, live-server claim, owner installation replacement or GitHub publication is part of this review.
