## Additional owner-reported update issue resolved

During implementation, the owner reported UNSUPPORTED_FORMAT updating the saved win collection. Read-only diagnosis reproduced it: two native Xray wrappers contained AmneziaWG options and an SS2022 method. The parser now reads the three supported SS2022 methods, validates PSK lengths and preserves identity-key chains; the editor lists those methods. An unsupported recognized external format inside a fully validated native Xray envelope can be reported/skipped in compatible import. Strict import, native version/schema validation and protected/TLS restrictions stay atomic. AmneziaWG remains unsupported and its options are never interpreted as regular WireGuard.

A read-only subscription details page is available from the collection menu and does not fetch/update until the separate Update action. A fresh read of the owner's win URL admitted 23 profiles with one unsupported item reported. This is import verification, not a connectivity guarantee. No owner store was saved by diagnosis. SS2022 configuration acceptance by the pinned engine is verified using synthetic keys, not the owner's credentials.

# Local UI review · 0.1.1-preview.1 · 2026-11-11

Private, owner-approved implementation of the six-view compact/expanded preview. Three shared palettes: light glass/lilac, dark blue glass and AMOLED. Default compact width is 480 logical pixels; sidebar width is 222. A full-window header centers the language flags independently of sidebar direction; narrow widths give flags a separate centered row. The English brand stays physically left inside its own frame, including Persian.

Profile cards have fixed 84-pixel height, separate latency and fixed 44-pixel actions. Overflow text moves inside clipped single-line fields at 24 pixels/second, with pauses; short text stays still. Motion defaults to on, reflecting the owner's explicit request. Settings offer on/off/follow Windows; high contrast stops motion. Unloaded/offscreen rows stop their animation clocks. This is native WPF animation, not a bitmap mockup or manual-only scrolling.

The hero shrinks from 148 to 88 while scrolling and retains the power button. Available monitor work area and DPI bound window geometry; short windows collapse the hero earlier. Actual physical touch, monitor migration and mixed-DPI hardware still need testing. A reported rendering tier is capability, not measured GPU utilization.

Connection/import/scanning/trust behavior is inherited from Beta. Only a display preference and fresh-window defaults changed in storage; existing saved window size is preserved if it fits. No new HY2/WireGuard engine or TUN implementation, live-server claim, owner installation replacement or GitHub publication is part of this review. See UI-0.1.1-preview.1.md for behavior and the accompanying evidence for checks of the delivered bytes.

# Rovunet Windows 0.1.0 Beta

Public Windows x64 beta based on reviewed preview20/final4. WPF/.NET10, four languages, compact/wide layouts, touch-size cards, separate unprivileged agent, local HTTP/SOCKS5 and optional Windows system proxy. No device-wide TUN or forced per-process routing.

Subscriptions support provider account usage/expiry separately from device counters. Profile editors, public-source import, in-place updates, tray connect/disconnect, select-then-connect cards, staged DNS compatibility/server tests, cancellation, checkpoints and multi-selection are implemented. Six banks are bundled; full60370 addresses and sample128 are distinct. Resolver transports are UDP/TCP/DoT/DoH where the selected family supports them.

The owner reports successful connection and data transfer on all tested paths except Hysteria2/WireGuard. This is owner-reported use, not a guarantee for every server/network. Those two engines remain known limitations. Public-feed downloads were intermittently unavailable; some custom protocol options remain unsupported and are rejected explicitly. TLS/SSH and protected restrictions stay enabled.

The beta changes version, packaging and documentation; connection code and engines retain the reviewed baseline. Exact source/asset hashes and beta verification accompany the release. Unsigned installer; target Windows10 22H2/build19045 or Windows11 x64. Program Files/UAC and physical touch/DPI/hardware suspend need broader testing. See TESTING.md and BACKLOG.md.
