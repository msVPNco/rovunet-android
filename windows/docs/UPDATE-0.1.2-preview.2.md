# Windows 0.1.2-preview.2 — local review

The three approved light/dark/AMOLED palettes now supply the same frozen surface and edge brushes to inner pages, buttons, input frames, ellipsis menus and submenus. Existing navigation, control locations, protocol ordering, touch targets, compact/wide behavior and mathematically centered flags remain. Protocol tiles use proportionate vector icons and overflow-only moving text. No text bitmap stretch, non-uniform scale or live blur is introduced. The Iran language flag is the owner-requested Lion and Sun vector; original SVG, geometry conversion and attribution are included in Assets.

AnyTLS, TUIC v5 and the single-binding Mieru sharing format are accepted directly and inside validated Android native Xray envelopes. Structured creation/editing preserves subscription identity and wrapper protections, masks secrets, retains exact no-op text and maps the shared Android/macOS settings to a separately pinned Mihomo adapter. Unknown options, duplicate parameters and insecure TLS flags are refused. Mieru supports TCP and UDP server transports; binary mieru://, ranges and multiple bindings are not silently simplified.

The extra helper reads configuration only on stdin, uses random authenticated loopback SOCKS, discards bounded native logs and belongs to the Agent's kill-on-close process job. The usual Xray HTTP/SOCKS endpoints and traffic counters remain the public endpoints. The outer local SOCKS endpoint remains TCP-only; native UDP fixture success does not imply a Windows TUN or public SOCKS UDP service.

Standalone DoH follows Android's `doh`/field21 mode: verified HTTPS DNS resolution and TCP forwarding, optionally through a preceding layer. Destination names have no plaintext/system DNS fallback. This mode alone does not encrypt arbitrary destination traffic; the UI explains the distinction. Initial resolution of the DoH provider hostname uses normal endpoint bootstrap.

Tor follows `snowflake`/field26. The official Windows expert bundle 16.0.1 was obtained from the EFF mirror and matched against Tor's published SHA256 (`9eed3c3ff1fe43df034ce360196c9ec95472560d77ff55614d0cd5120edea27b`). OpenPGP verification is not claimed. Every bundled file, including data/default bridges, is pinned by a manifest whose own hash is compiled into the Agent. Config goes through stdin; an owner-only session directory, hidden processes, process-job ownership, 100% bootstrap readiness, bounded startup/cancellation and cleanup are enforced. Default Snowflake and supported explicit bridge lines are available. A preceding layer is applied to Tor and its transports without a direct retry.

Chains contain two to four self-contained profile layers, in outer-to-inner order, using Android ChainValidation rules. No nested chains, duplicate identity, combined DNS+SSH layers or sharing-disabled members. Singleton bridge groups cannot repeat; SSH/SOCKS5 may repeat. Slipstream is outermost only. Xray-family protocols are limited to a two-layer outer-Xray/inner-SSH chain. DNS families consume preceding SOCKS; DNS-over-TCP replaces UDP where required. Naive consumes the preceding HTTP CONNECT endpoint. SSH identity approval and changed-key rejection apply to the exact layer. Failure tears down all stages in reverse order, with no freedom/direct fallback. Chain portability to Android is not claimed: the Android reference stores chain IDs in its own database rather than defining this Windows self-contained sharing format.

Local evidence includes encrypted native TCP/UDP AnyTLS, TUIC and Mieru TCP/UDP fixtures; successful Windows Agent/Xray/authenticated-helper Mieru traffic; real-helper rejection of the fixture CA for AnyTLS/TUIC; verified DoH destination resolution and unknown-root rejection; two/four-layer traffic with exact hop counts, no direct fallback when the outer layer fails, chained SSH traffic and trust rejection; actual Tor configuration validation and bootstrap cancellation. Synthetic test roots stay inside test processes and never enter Windows certificate stores.

An isolated external Tor attempt did not reach bootstrap/HTTPS success within 150 seconds on the current network; it cancelled cleanly and left Windows proxy settings unchanged. External provider acceptance for the new protocols, all possible chain combinations, physical sleep/touch/mixed-DPI and GPU load/FPS are not claimed. WPF reports rendering Tier2; saved RenderTargetBitmap previews are visual evidence, not GPU-performance measurements. See the delivered VERIFICATION.json for exact final-package checks.

Existing AmneziaWG and the previous manual-form cleanup remain. The 60,370-address Default resolver bank, inline collection tests/stop, trust and telemetry behavior, installer defaults and upgrade logic are retained. Published 0.1.1 Beta bytes/tag and Android/macOS files remain unchanged. This local review does not authorize GitHub publication or replacement of a published asset.
