# قرارداد ورودی و وضعیت حساب

مرجع: Android tag v0.3.0-alpha16 و panel commit
`212eda55af6faa4662c8648e0fc863fe652b8fa7`، خصوصاً:
`internal/handlers/account_status.go`، `subscription.go` و `internal/clientcfg/fields.go`.

ورودی اختصاصی: نسخه‌های دقیق 22، 28، 29، 30، 31، 32 و 33؛ تعداد فیلد دقیق کنترل
می‌شود. v33 اعتبارهای lossless را از فیلد 87 (base64 JSON) می‌خواند و متن اصلی را
برای حفظ انتخاب‌ها نگه می‌دارد. قالب‌های قدیمی‌تر دیگر و آینده، کلید ناشناختهٔ JSON،
نسخهٔ ناشناخته و ورودی نیمه‌معتبر رد می‌شوند. ورودی feed اتمی است.
v32 فیلدهای 85/86 مجموعه دارد؛ v31 فیلد 84 coreLink دارد. نسخه‌های v22/v28 پنل
هم پشتیبانی می‌شوند؛ پنل فعلی همهٔ مسیرها را فقط v33 صادر نمی‌کند.

قفل، هش قفل، انقضا، device binding و resolver مخفی باعث رد ورودی می‌شوند؛ این
محدودیت‌ها حذف یا downgrade نمی‌شوند. رمزگشایی proprietary و bundle قفل‌شده هنوز
پیاده نشده است. نسخهٔ بازمتنِ پروفایل عادی allowSharing=0 با پروفایل قفل‌شده یکی نیست؛
متن اصلی آن حفظ می‌شود و قابلیت export در این نمونه وجود ندارد.

feed JSON:

```json
{"version":1,"name":"Collection","items":[{"id":"path-1","link":"<profile>"}]}
```

فقط HTTPS، بدون redirect خودکار یا TLS bypass؛ حداکثر ۲MiB، ۱۰۰۰ آیتم، ۲۰ثانیه.
توکن یا URL وارد لاگ نمی‌شود. source ID از URL کامل هش می‌شود؛ همهٔ آیتم‌های یک
اشتراک در یک کارت‌اند. update با همان item ID انتخاب قبلی را حفظ می‌کند؛ حذف مسیر
منتخب باعث انتخاب خودکار مسیر دیگری نمی‌شود.

وضعیت: `/sub/<token>.json` → `/sub/<token>.status.json`، جدا از feed. نسخهٔ ۱:
server_id/account_id/period_id هرکدام ۳۲hex؛ شناسهٔ دوره بعد تمدید تغییر می‌کند.
revision مختص URL است، حتی هنگام تمدید؛ توکن جدید مقایسهٔ مستقل دارد. revision
کمتر یا دادهٔ متفاوت با revision یکسان رد می‌شود. زمان‌ها می‌توانند با همان revision
تازه شوند. هیچ جمع‌زدن سهمیه برحسب تعداد آیتم/نشانی/پروتکل وجود ندارد.

`limit_bytes=null` و `used_bytes=null` فقط با `not_metered` نامحدودند؛ null صفر نیست.
واحد GiB برابر 1024^3 است، used_bytes جمع دو جهت. complete/partial/unavailable/
not_metered جدا هستند. زمان HTTP Date با ساعت monotonic جلو برده می‌شود؛ پرش ساعت،
داده یا نمونهٔ بیش از ۱۵دقیقه، تاریخ آیندهٔ بیش از ۵ثانیه، شمارش ناقص و نبود Date
وضعیت را نامطمئن می‌کنند. عدد/رنگ مطمئن برای دادهٔ نامطمئن نمایش داده نمی‌شود.

آستانه‌ها: باقی‌ماندهٔ ≤۲۰٪ یا ≤۳روز زرد؛ ≤۵٪ یا ≤۲۴ساعت قرمز. expired و
limit_reached جدا هستند. ۴۰۴ اطلاعات ناموجود است؛ برای حساب expired فایل status
ممکن است باقی بماند در حالی که feed حذف شده است؛ به همین دلیل status مستقل دریافت
می‌شود. کنترل سهمیه فقط سرور است و هیچ نتیجهٔ status اتصال دستی را مسدود نمی‌کند.

فعلاً تازه‌سازی با اقدام کاربر در پنجرهٔ اشتراک است؛ polling دائمی وجود ندارد.
تایمر یک‌باره فقط نمایش قدیمی را نامطمئن می‌کند. cache وضعیت پس از اجرای دوباره
معتبر فرض نمی‌شود. توسعهٔ تازه‌سازی محدود هنگام دیده‌شدن Home در backlog ثبت شده است.
