## نسخه و هویت

نسخهٔ عمومی جاری **0.3.0-alpha15 Full، کد ۲۶** است. بستهٔ `app.veyra.client` و امضای تولیدی آلفا۱۴ حفظ شده‌اند؛ ارتقا نیاز به حذف برنامه ندارد. آلفا۱۱ تاریخی و بسته‌های خصوصی هویت متفاوت دارند. [ثبت انتشار](releases/alpha15.md) · [امضا](SIGNING-IDENTITY.md) · [ارتقا](UPGRADE.md).

## اصلاح و شواهد

- نقص حذف اعضای رابط Go/JNI در Release بهینه‌شده با قواعد مشترک در AAR و اپ اصلاح شد؛ R8 روشن است.
- سورس واقعی ساخت: `908253b42082bbd80007677f0369792d324a378f`. [CI موفق](https://github.com/msVPNco/rovunet-android/actions/runs/42215030490): ۵۰ آزمون JVM، ۳۱ Debug خصوصی و دو بررسی JNI روی Release خصوصیِ بهینه‌شده، صفر skip.
- آزمون دستگاه: شبیه‌ساز API 30/x86_64، شامل عبور واقعی TUN/MTU از UID جدا، اعتماد و توقف SSH، اسکن، مهاجرت/بازیابی، انتخاب/نتایج کارت‌ها و فارسی/RTL. آزمون‌های JNI افزوده، ساخت/توقف کلاینت‌ها و خطای native واقعی را بدون سرور دوردست اجرا می‌کنند.
- APK عمومی با کلید تولیدی قبلی امضا و از نظر نسخه، بسته، گواهی، ABI واقعی DEX، CRC/هم‌ترازی و تمام ۳۳ کتابخانه بررسی شد. هر ۲۱ ELF64 هم‌ترازی ۱۶KB دارند. موتورهای DNS عوض نشده‌اند؛ سه فایل Xray از همان سورس پین‌شده بازسازی شده و هش متفاوت دارند. فهرست کامل در VERIFICATION.json است.
- خطاهای مقدماتیِ ساخت و اجراکنندهٔ آزمون ثبت و برطرف شدند: کمبود heap بسته‌بندی و وابستگی AndroidJUnitRunner به کلاس حذف‌شدهٔ Trace. اجراکنندهٔ نهایی فقط از Instrumentation اندروید و بررسی‌های Java مشترک استفاده می‌کند؛ هیچ کپی Go/AndroidX در APK تست ندارد و نتیجهٔ ناقص پذیرفته نمی‌شود.
- گزارش native اولیه به‌تنهایی پشتهٔ لازم برای تعیین علت همهٔ خروج‌ها را نداشت. یک نقص مستقل در APK منتشرشده اثبات و اصلاح شد؛ تأیید انتشار توسط مالک، نتیجهٔ میدانی تازه محسوب نمی‌شود.
- مشکل مجموع مصرف بنا به گزارش کاربر رفع‌شده است و برای آن تغییر تازه‌ای در این نسخه انجام نشد.

## رفتار حفظ‌شده

اتصال دستی بدون پیش‌تست/اسکن اجباری؛ انتخاب صریح و نتایج پایدار؛ لمس اول انتخاب و لمس دوباره اتصال؛ کنترل‌های مستقل مجموعه و مسیر؛ تأیید هویت SSH/TLS؛ رمزگذاری Keystore؛ تم روشن/تیره/AMOLED و منابع اصلی چهار زبان. Soar و Soar+SSH جدید پیش‌فرض UDP + TCP دارند؛ انتخاب موجود/واردشده حفظ می‌شود. جزئیات پروتکل‌ها و محدودیت معماری در README است.

## موارد میدانی باز

۱. مسیر دادهٔ SOCKS روی سرور گزارش‌شده و تفاوت Soar auto/on به دادهٔ کنترل‌شدهٔ تازه نیاز دارند؛ از شکست DNS نمی‌توان ACL یا فیلترینگ را قطعی نتیجه گرفت.
۲. اتصال/تعویض resolver در APK عمومی جدید باید روی گوشی و شبکهٔ واقعی هم بررسی شود. موفقیت شبیه‌ساز تضمین همهٔ نسخه‌های اندروید یا اپراتورها نیست؛ MTU به‌تنهایی پنهان‌ماندن از DPI را تضمین نمی‌کند.
۳. برخی متن‌های پیشرفتهٔ به‌ارث‌رسیده ممکن است انگلیسی بمانند؛ ترجمهٔ منابع با پوشش معنایی تمام پیام‌های backend یکسان نیست.
۴. سورس native کامل و بازتولید مستقل همهٔ باینری‌های به‌ارث‌رسیده ادعا نمی‌شود؛ یک درخت پین‌شدهٔ قدیمی dnstt-mobile در دسترس نیست. manifest آرشیو این محدودیت را ثبت می‌کند.
۵. اشتراک دوره‌ای، failover خودکار مجموعه، سنجش throughput و نسخه‌های فروشگاهی/دسکتاپ در این انتشار اضافه نشده‌اند. دریافت به‌روزرسانی همچنان به دسترسی GitHub وابسته است.
