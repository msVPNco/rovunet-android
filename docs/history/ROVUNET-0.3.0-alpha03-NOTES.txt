Rovunet 0.3.0-alpha03 — review follow-up

Account hints accept only [protocol] user=account. Plain labels such as Rovunet,
old [vless] labels and no-account headings clear the hint. Anonymous unanchored
profiles do not merge with each other merely because a server address matches. Native collection
metadata remains authoritative. The manager prints explicit headings for both
native and standard links. TestFullPanelTextContract runs actual showUserConfigs
for two users and Kotlin asserts two groups of three profiles each.

Regroup preserves names while inferring membership, previews old/new names and
stores a one-level undo snapshot in private SharedPreferences before the database
update. Snapshot includes only profile IDs and old/new grouping metadata, not
connection credentials. Undo preserves current connection settings and skips deleted
profiles. Conflicting later group edits abort undo rather than overwrite them.
The snapshot survives app restarts; Android process-death/UI behavior is not device-tested.
A subsequent regroup replaces the previous undo snapshot.

CI pins the manager SHA in tools/veyra/MANAGER_REF, verifies Maven JAR checksums,
caches JARs/Go builds and runs tests on pushes/PRs. APK builds only run on tags or
workflow_dispatch. The matching manager commit is local and must be published
before checkout can succeed. No authenticated GitHub workflow dispatch was available;
no remote CI execution is claimed. The Full native preparation step is now explicit.
JSON dependency is pinned to 20250517, matching the locally tested JAR and checksum.

READ_PHONE_STATE, READ_EXTERNAL_STORAGE and WRITE_EXTERNAL_STORAGE were implied
by the Go binding manifest's legacy target SDK, per manifest merger report.
They are removed explicitly. QUERY_ALL_PACKAGES remains for split tunneling.
Tor/Snowflake, file import/export and Android 7 still require phone validation.
Removal does not guarantee Google Play Protect's Uncommon warning disappears.
This is still a debug-signed alpha build; release signing is a separate remaining task.

Numeric IPv6 origins normalize without hostname DNS lookups. importAccountHint
moves to the end of ServerProfile's constructor. Existing commit history
was not rewritten merely to split old gofmt whitespace changes.

Still pending from the earlier review: alternate HTTPS target, full resource-based
localization, CollectionTester extraction/virtual-time cancellation tests, optional
Salamander generation, and device/background/network-loss testing.

Collection cards now offer Export / Share collection, opening the Copy/Share dialog.
Only the chosen group is exported, with collection ID/name preserved. Locked profiles
are re-encrypted only if sharing is allowed; otherwise the entire export is rejected
instead of silently omitting a member.
