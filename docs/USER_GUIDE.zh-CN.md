尚未证实已修复实体手机上 Hev 停止耗时 120 秒的问题；已修正错误的屏幕关闭记录。模拟器测试不证明实际网络可用、整夜/Doze 稳定或省电。未发布新的 Lite 或桌面安装包。将 Patterniha 移至 Anonymous/Mahsa 同组的调整留待下次更新。

Panel v1.19 状态在原卡片中显示剩余 GiB 与时间。黄色：≤20% 或 ≤3 天；红色：≤5% 或 ≤24 小时。不限量、未知和过期分别显示。404、过旧或不完整的计量不是过期证明。仅主页可见时刷新状态，不阻止手动连接；实际计量和限制以服务器为准。

**公开 alpha14 至 alpha16（截至代码32）需要直接升级：**下载 [Full APK](https://github.com/msVPNco/rovunet-app/releases/download/v0.3.0-alpha17/Rovunet-v0.3.0-alpha17-Full.apk) 并覆盖安装，**不要卸载或清除数据**。旧更新器内置原仓库地址，网页重定向不能修复该检查。包名与生产签名不变。若已安装获批准的 alpha17/代码36 测试 APK，就是同一个文件，无需重装。

HTTPS 订阅提供 **更新** 和 **导入**。新来源一次导入成功后关闭整个窗口；错误保留表单，重复来源地址被拒绝，本地编辑得到保留。更新已有来源前须断开 VPN；移除旧条目仍需审核。可选自动刷新约每 12 小时在合适的网络/电池条件下运行。小集合可用 QR/PNG 分享，过大集合使用文件。

Soar 扫描有快速、高级、E2E 和 Prism。快速/Prism 用配置的 Ed25519 密钥验证真实 Soar 握手；E2E 还验证 HTTP 204 或使用已批准服务器身份的 SSH 账户。高级模式只诊断 DNS。UDP/TCP 独立测试，Soar 扫描默认两者，不改写已保存的连接选择；丢弃旧协议的证明时保留导入的候选地址。

## 安装与更新

版本为 **alpha17 Full，代码 36**。从[公开发布](https://github.com/msVPNco/rovunet-app/releases/latest)下载签名 APK，直接覆盖公开 alpha14，无需卸载；包名和生产签名均不变。旧 alpha11、私有 Rovunet Test 的身份不同，参见[迁移](UPGRADE.md)。未签名文件不能安装。

需要 Android 7.0/API 24，支持目标 ARM32/ARM64/x86_64，继承的 Naive/Tor 不提供 x86_64。没有承诺新的 Lite 或商店/桌面版本。

升级前阅读签名说明并保留可读取配置的旧安装。密码加密批量导出排除锁定配置；禁止分享/绑定设备的配置可能需要管理员原链接或重发。不要把卸载或清除应用数据作为常规排障步骤。[迁移](UPGRADE.md)。

设置中的更新功能在应用内下载兼容 GitHub APK，验证哈希、包名、版本和签名，再交给 Android 安装器。需要访问 GitHub，不静默安装；不兼容签名会被拒绝。公开预览频道可选，私有包单独交付。

## 导入与连接

用 + → 导入选择文本、文件或支持的 QR，检查预览后确认。支持 rovunet://、兼容 veyra:// / slipnet://、支持的 VLESS/Hysteria2 链接与单对端 WireGuard INI；原生导出 v33，未来未知格式明确拒绝，请更新应用而非删除安全字段。

集合保存路径、明确选择与完成的测量。标题/箭头只展开折叠；第一次点击路径选择，再次点击已选路径连接。返回时记住的路径已经选中。编辑、删除和菜单不会连接；集合按钮连接记住的或合适的初始路径，不强制先测试，也不悄悄替换明确选择。

授予 VPN 权限。未知 SSH/自签名身份须先与管理员核对指纹，后台不自动批准新身份。使用主按钮、集合按钮或路径菜单取消启动/断开；若停止一直未完成，请报告，不要反复连接。已连接表示技术就绪，不保证每个网站可用；空闲零流量不自动说明故障。

## 测试与 DNS

断开时另行执行集合测试：真实隧道内 HTTPS/204、证书验证与有限备用目标。显示时间、成功比例和延迟波动，不是下载速度或长期稳定性。历史失败不阻止手动连接，不同网络结果分别标记。

直接路径优先；进入 DNS 回退需同意，解析器测试/发现可能持续数分钟且可取消。手动 DNS 路径使用已有解析器，不强制扫描。

新建 Soar/Soar+SSH 默认 UDP + TCP，已有/导入选择保留。自动先用 UDP，并可能为反复失败且未验证的路径添加 TCP，不等于一开始同时使用两者。SSH 叠加 Soar 还需要服务器允许 SSH 目的地址/端口。

## 凭据、界面与诊断

存储秘密使用 Android Keystore 加密。不可读记录会要求显式恢复而非静默清空；需要匹配的原配置/管理员。卸载后 Keystore 不是便携备份。分享限制保留，客户端锁不保证防御修改版客户端；备份请用强密码并验证能导入。

设置提供四语言与浅色/深色/AMOLED。部分高级扫描器文本及后端错误仍可能英语，技术地址/语法不翻译。通知、桌面组件和快捷开关依赖 Android 权限与启动器。

反馈提供版本、协议、步骤与网页实际表现。安全报告只包含类型化阶段/代码、Soar 配置模式和 UI 计数快照，不含端点/账号/凭据字段；不自动发送。继承的详细调试日志可能敏感，请先审阅脱敏，不公开真实配置、密码、私钥或设备 ID。

远程 SOCKS 数据路径和 Soar auto/on 差异仍需实测。CONNECT 成功不证明数据通过，DNS 错误不证明审查或 ACL。DoH 单独只加密 DNS，普通 SOCKS5 不加密传输。未包含自动路径切换与吞吐量基准。[状态](STATUS.md) · [Telegram](https://t.me/RovunetVPN)。

alpha15 修复 Release 打包时 Go/JNI 成员被删除的问题。更新后如再次退出，请重新打开应用，附上新事件的时间与安全报告；旧退出记录可能在升级后仍保留。
