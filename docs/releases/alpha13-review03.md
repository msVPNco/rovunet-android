# آلفا ۱۳، بستهٔ خصوصی review03

نسخهٔ `0.3.0-alpha13-review03`، کد ۲۱، شناسهٔ `app.veyra.client.candidate`، نام Rovunet Test. امضا همان گواهی سه بستهٔ خصوصی قبلی است. روی review02 با کد ۲۰ بدون حذف برنامه نصب شد. برنامهٔ عمومی، داده‌های آن و امضای انتشار مستقل‌اند. انتشار عمومی و اجرای workflow روی میزبانی GitHub انجام نشده‌اند.

## تغییرات اصلی

- آخرین مسیر انتخاب‌شده برای هر مجموعه جدا و رمز‌شده نگه داشته می‌شود. انتخاب مجموعه و بازگشت به اپ آن را پاک نمی‌کند. اتصال دستی به همان مسیر می‌رود؛ تست پیش‌شرط اجباری آن نیست. انتخاب اولیهٔ خودکار، شکست تازهٔ همان شبکه را کنار می‌گذارد.
- اتصال موقتِ تست، active profile یا آخرین اتصال عادیِ کاربر را بازنویسی نمی‌کند.
- توکن بازبینی حذف از کلید مقایسهٔ کانفیگ کنار گذاشته شد. فعال‌سازی، تغییر زمان اتصال، سنجاق یا مرتب‌سازی دیگر نتایج را پاک نمی‌کند. حفاظت تراکنشی حذف و بررسی ciphertext همچنان برقرار است.
- نتایج کامل با زمان و تأخیر، آمار مجموعه و برچسب تاریخی نگه داشته می‌شوند. تغییر شبکه نتیجه را تاریخی می‌کند؛ تغییر تنظیم اتصال یا حذف کانفیگ شاهد همان کانفیگ را نامعتبر می‌کند. کش رمز‌شده سقف ۲۰۰۰ نتیجه/انتخاب و هفت روز سابقه دارد؛ انتخاب فعلی در سقف حافظه اولویت دارد. پیشرفت ناتمام و resolver کشف‌شده ذخیره نمی‌شوند.
- پین TLS به SPKI تغییر کرد. مهاجرت از pin قدیمی فقط با همان گواهی تأییدشده انجام می‌شود؛ تعویض کلید یا ناهماهنگی pin قدیمی بی‌صدا پذیرفته نمی‌شود.
- کنترل تلاش احراز هویت برای کلاینت‌های LAN، تنظیم Network Security و متن صریح HTTPS 204 اضافه شدند. ترافیک local TUN از محدودیت تلاش LAN مستثناست. سیاست Android جای بررسی raw socket و native را نمی‌گیرد.
- سه فایل موتور مردهٔ TUN حذف شدند؛ نوع زندهٔ ResolverConfig مستقل حفظ شد. ۳۳ کتابخانهٔ native بایت‌به‌بایت ثابت ماندند و بازسازی نشده‌اند.
- سه قرارداد انتخاب، فاز تست و watchdog به `app/src/test` منتقل شدند. تست‌های جدید همان مسیر را دارند؛ Gradle و job مستقل verify همان مجموعهٔ JUnit را اجرا می‌کنند. جارهای تازه نسخه و SHA-256 ثابت دارند.
- همهٔ ۴۴۹ منبعِ تعریف‌شدهٔ قابل‌ترجمه در چهار زبان از نظر حضور/آرگومان بررسی می‌شوند؛ این به معنی ترجمه‌شدن تمام متن‌های خام ارثی نیست. متن‌های تازه کلید معنایی دارند.
- گیت هم‌ترازی ELFهای ۶۴بیتی، گارد افزایشی Kotlin، پین gomobile به نسخهٔ go.mod و شش ADR اضافه شدند. متن آماده‌سازی کانفیگ‌ها در بارگذاری اولیه نمایش داده می‌شود.

## اعتبارسنجی

- بیلد نهایی پاک و آزمون‌های استاندارد Gradle: ۱۴ آزمون، صفر شکست/خطا/skip.
- harness مستقل JVM و JUnit: همان ۱۴ آزمون گذشتند؛ قراردادها، آزمون شبکه، نشست، TLS و هسته نیز گذشتند.
- دروازهٔ دستگاه: ۱۹ آزمون روی شبیه‌ساز Android 11، صفر شکست و صفر skip؛ شامل هویت SSH/STunTLS، MTU و عبور ۴۸۰۰ بایت از UID دیگر، اسکن، مهاجرت و بازیابی اعتبارنامه.
- پس از سخت‌گیرانه‌ترشدن انتظار برای مشاهدهٔ تغییر واقعی SQL، دو آزمون انتخاب و نتایج با APK آزمون نهایی دوباره اجرا شدند: دو موفق، صفر شکست/skip. این دو اجرای مجدد جزو همان ۱۹ سناریو هستند، نه دو قابلیت اضافه.
- آزمون انتخاب با SSH واقعیِ fixture محلی به مسیر انتخاب‌شده متصل شد. آزمون نتایج، پاسخ خطای واقعی SOCKS، پایان سرویس، تغییر ترتیب و زمان در SQL، بازگشت Activity و خواندن سردِ تاریخچهٔ رمز‌شده را بررسی کرد. این‌ها آزمون سرور یا شبکهٔ واقعی کاربر نیستند.
- TLS واقعی: مهاجرت pin قدیمی، گواهی تمدیدشده با همان کلید، رد کلید جدید و رد ناهماهنگی pin قدیمی آزموده شدند. اعتبار گواهی و hostname ضعیف نشد.
- هر ۲۱ ELF شصت‌وچهاربیتی LOAD با هم‌ترازی حداقل ۱۶KB داشت؛ گیت خودکار برای APKهای آینده نیز افزوده شد. هر ۳۳ کتابخانه با review02 برابری SHA-256 داشتند.
- aapt: کد ۲۱، minSdk 24، targetSdk 35 و compileSdk 36 تأیید شدند. apksigner: v2 معتبر، v1 و v3 غیرفعال؛ برای حداقل API 24 معتبر است. این گواهی Android Debug و مخصوص بستهٔ خصوصی است.
- اولین تلاش دستگاهی به‌دلیل ناپایداری Network Stack خود شبیه‌ساز پیش از نصب کنار گذاشته شد. اجرای موفق روی شبیه‌ساز پاک انجام شد؛ خطای محیط به‌عنوان موفقیت حساب نشد.

ارزیابی هر ۱۹ پیشنهاد، موارد اعمال‌شده و دلیل تعویق/رد بقیه در [گزارش تصمیم‌ها](../reviews/alpha13-review03-decisions-fa.md) آمده است. پچ این نوبت روی کامیت review02 یعنی `50cd188` اعمال می‌شود و جای سه پچ قبلی را نمی‌گیرد. عبور دادهٔ SOCKS و کامل‌شدن Soar+SSH روی سرور واقعی کاربر همچنان نیازمند بررسی‌اند. تست گوشی پیش از انتشار عمومی لازم است.
