# Rovunet macOS 0.1.6 Beta

**Предварительный выпуск · macOS 15+ · Apple Silicon arm64 / Intel x64**

Функциональная база Apple Silicon проверена и одобрена владельцем на настоящем Mac. **Intel: ограниченное тестирование** — проверки на хосте и анализ пакетов, без запуска на физическом Intel Mac. Возможности dev.6 сохранены; версии приложения и установщика обновлены до 0.1.6 Beta.

- Компактный интерфейс Mac, три темы и четыре языка, закреплённое сохранение/применение, прокрутка длинного текста. Значок меню: белый — отключено, жёлтый — подключение, зелёный — подключено, красный — ошибка.
- Поиск DNS для конкретного профиля: Simple, Advanced, E2E и Prism. Ответ DNS, достижимость сервера и необязательный HTTPS измеряются отдельно. Вторую проверку туннеля можно запускать вместе с поиском; выбранные результаты применяются к исходному профилю.
- Необязательный системный TUN, системный и локальный прокси для приложений вроде Telegram. Совместимая установленная служба TUN той же архитектуры используется повторно.
- SSH и Slipstream получают идентификатор сервера и запрашивают доверие при первом использовании. Ручное подключение не зависит от пинга или сканирования.
- HTTPS-подписки, импорт, объём/срок по данным панели, ручной/аварийный/умный выбор пути; AnyTLS, TUIC и Mieru с одной привязкой вместе с прежними протоколами.

## Установка

Для M1/M2/M3/M4 и более новых M-серий используйте **AppleSilicon-arm64**; для Intel — **Intel-x64**. Требуется macOS 15+. Air/Pro и размер экрана не требуют отдельных пакетов.

Закройте прежнюю программу через Command-Q, установите PKG и откройте Rovunet из Applications. Альтернатива: откройте DMG и перетащите Rovunet в Applications. Сохраните профили и элементы Keychain. При первом использовании системного VPN установите службу TUN в настройках и включите System-wide VPN (TUN); совместимую службу повторно устанавливать не нужно. Установка и изменение настроек сети могут запросить разрешение администратора.

В редакторе профиля откройте поиск DNS, отметьте результаты и нажмите закреплённую галочку сверху; сохранение формы также доступно через Command-S. Полные документы/несколько привязок Mieru, произвольные цепочки и принудительная маршрутизация приложений без собственного прокси пока не включены. Точные файлы и область проверки перечислены в SHA256SUMS.txt, VERIFICATION.json и архивах исходного кода.
